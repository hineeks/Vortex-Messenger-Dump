# 🌀 Vortex Messenger Dump - Web Dashboard Run

Запуск веб-приложения:

```bash
# 1. Установка зависимостей
pip install -r requirements.txt

# 2. Запуск веб-сервера
python -m flask --app vortex_dump.app run

# 3. Откройте в браузере
http://localhost:5000
```

## 🚀 Использование

1. Загрузите JSON файл с данными мессенджера
2. Смотрите статистику и анализ
3. Ищите сообщения
4. Экспортируйте данные в нужном формате

Готово! 🎉
