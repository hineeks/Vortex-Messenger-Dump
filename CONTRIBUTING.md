# Vortex Messenger Dump - Contributing Guide

Спасибо, что рассматриваете возможность внесения вклада в наш проект!

## Как помочь

### 🐛 Сообщение об ошибках

Если вы нашли баг:
1. Проверьте [Issues](https://github.com/hineeks/Vortex-Messenger-Dump-Sbork-/issues), может быть это уже известно
2. Создайте новый Issue с подробным описанием
3. Включите примеры кода и версию Python

### 💡 Предложение функций

Есть идея улучшения?
1. Откройте Issue с тегом `enhancement`
2. Опишите проблему, которую это решает
3. Укажите примеры использования

### 🔧 Отправка кода

1. **Fork** репозиторий
2. **Создайте ветку** для вашей фичи:
   ```bash
   git checkout -b feature/AmazingFeature
   ```
3. **Commit** ваши изменения:
   ```bash
   git commit -m 'Add some AmazingFeature'
   ```
4. **Push** в ветку:
   ```bash
   git push origin feature/AmazingFeature
   ```
5. **Откройте Pull Request**

## Требования к коду

- Следуйте PEP 8 стилю
- Добавьте docstring для функций
- Напишите тесты для новой функциональности
- Обновите документацию

## Запуск тестов

```bash
pytest tests/
```

## Ветвление

- `main` — основная ветка (стабильные релизы)
- `develop` — ветка разработки
- `feature/*` — новые фичи

Спасибо за вклад! ⭐
